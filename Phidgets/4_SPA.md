# Adding phidgets to a SPA

Up to this point we've been working with Phidgets in a single html file. This is great for quick prototyping, but when it comes to building a fully featured web application, you'll likey use a framework instead of working directly with html.

Phidgets is easy to add to most front-end frameworks. In fact it works just the same as we have been building it out today. The only different is each framework comes with their own "reactivity framework" that we'll want to use to update the UI, instead of manually making update like we have been doing. 

This repo contains 3 examples of using Phidgets in popular front-end frameworks. If already familiar with one of these, explore the example to see how to setup Phidgets in your applications. If you haven't worked with any of these frameworks before, we suggest starting with 4a_Vue. It's what we use at Dimensional Innovations, and is fairly simple to pick up as a beginner.
